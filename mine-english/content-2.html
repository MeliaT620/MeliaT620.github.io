Daily Learning

Review、Build、Coach，
都藏在同一条向下流动的学习河流里。

它们是系统在后台理解课程的方式，不是三个需要你自己切换的页面。对你来说，始终只是当前这一页，然后继续往下。

REVIEW · BACKSTAGE

把正在变模糊的 Usage 找回来

系统挑出最值得重新唤起的知识，不把一整张“待还清”的复习清单压给你。

BUILD · BACKSTAGE

再建立一个新的 Usage

一屏只做一个认知任务。一词多义，也是一义一义慢慢建立。

COACH · ONLY WHEN NEEDED

只在需要时，多走一步

辨析、迁移和重点错项仍然嵌在这条流里，不突然把你带去另一套复杂界面。

✓
Today's Learning Complete 今天真正需要完成的学习，到这里就结束了。
Learning ends the obligation.

系统可以有很多分支，用户始终只有一条路。 一页一个知识点，继续往下；刷到底，就是完成。

Reflection · Optional

Reflection 也很简单。
今天学过的 Usage，一个一个再遇见。

只回看今天真正经过的知识。有限、安静，刷到最后就结束。

issue verb
The embassy issued her a visa.
大使馆给她签发了签证。
签发；发放
to officially provide or give something, especially a document
“我以前只记得 issue = 问题。把『签发 / 发放』作为独立 Usage 再遇见一次以后，终于不会混成一团了。”
精选评论会轻轻出现 ↓ next usage

今天学过的 Usage，再轻轻遇见一次。

Example 先出现；意义随后跟上。没有编号，也没有多余标签。

只出现今天真正学过的内容 评论与操作退到边缘，不抢知识的第一注意力 有限 Feed，刷完自然结束
Learning 完成任务。Reflection 留给兴趣。

One collection · different learning atoms

单词与句子不是两门课，
而是一条慢慢向现实靠近的学习链。

Mine 不希望你先背完几百个旅游词，过很久才去碰句子。更自然的是：先建立一小组真正需要的 Words，然后很快进入与它们对应的 Sentences。

Word→Usage→Sentence→Real Situation

Collection 决定“这一阶段我要学哪一套语言”；不同 App 只决定“我现在从哪个粒度去掌握它”。

Mine Words把 Word / Usage 学清楚。产品可以独立维护，也可以独立订阅。
Mine Sentences把完整表达真正听懂、说出来。产品可以独立维护，也可以独立订阅。
Future只有在一种新的认知任务真的值得独立存在时，才增加新的 App。

App 可以分，学习旅程不能分。 你不是在维护几个 App 的 streak，你只是在持续学习自己的 English。

今天在 Mine Words 学 12 分钟、在 Mine Sentences 学 8 分钟，最终都属于同一个 Mine Learning Day。
